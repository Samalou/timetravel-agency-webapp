# TimeTravel Agency — Webapp Interactive

Projet réalisé dans le cadre du **Mastère 1 (Ynov Campus)** : *TimeTravel Agency — Webapp Interactive*.

Cette webapp présente une agence fictive de voyage temporel premium, proposant **3 destinations** (Paris 1889, Crétacé -65M, Florence 1504) avec une interface moderne, immersive et interactive.

## 🎯 Objectif du projet

Développer une webapp interactive permettant aux utilisateurs de :

- Découvrir les destinations temporelles avec une interface immersive
- Explorer des pages détaillées pour chaque époque
- Interagir avec un agent conversationnel (chatbot)
- Obtenir des conseils et informations sur les voyages temporels
